# CORE — одностраничный лендинг

Маркетплейс результатов научной деятельности университетов. Один статичный файл `index.html`
(без сборки), публикуется через GitHub Pages из ветки `main`.

Локально: `python3 -m http.server 8792` и открыть http://localhost:8792.

Заявки из формы уходят через FormSubmit на почту, указанную в `ENDPOINT` внизу `index.html`.
